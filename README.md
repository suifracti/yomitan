## 使用

- 文章/字幕：按住 **Shift** 悬停查词；中文释义由内置 ECDICT 提供。
- 视频：asbplayer 使用平台可检测字幕，或拖入自己的 SRT/VTT；不保证任意网站字幕自动可读。
- 视频语境制卡：使用 asbplayer 的制卡入口，或在 Yomitan 加词后用 asbplayer 更新上一张卡片补入音频/截图。普通查词制卡无需额外服务。
- **高级词汇状态标色依赖额外 yomitan-api 本机组件，当前包不启用。** 已预设 Word 字段和目标牌组，但不把配置称为已完成 Anki 复习回流。21 天等“成熟”阈值是软件规则，不是真实掌握。

## 当前版本：同一张卡连续理解

`zh-study7` / `26.10.8.3` 不再提供固定详解的新标签、第二弹窗、侧栏或速览/用法模式切换。当前查词卡直接放完整 ECDICT 中文释义、IPA、顶部词形/考试标签/原始语料词频、原句与 AI 结果；Wiktionary 英英与源例句接在同一卡内。鼠标移开不再关闭，点 **×** 或 **Esc** 退出；卡内再查词复用当前卡，来源标为词典解释，不冒充网页原句。长词条仍可能滚动，但语境与常用操作不在所有词典内容之后。

- **英英辅助中文**：每组最多 3 个原义项，首个源例句直接可读，更多例句就地展开，更多义项用上一组/下一组。点「AI 中文 · 本组」才发送本组；保留原英文和源归属，明确标为 AI 辅助中文。超长段只发前 1800 字并提示，单批最多 4000 字；缓存命中不生成，失败、错序不写缓存。
- **原句与用法**：原句、已有译文、当前词的语境解释和短提示直接可见，不重复展开用法；可在同卡调整不完整原句或明确带上局部邻句。点击 AI 才调用，不在悬停、分页或恢复缓存时发送。
- **词典与数据**：一份增强 ECDICT 770611 条作中文资料，WTY/Wiktionary 作完整英英与真实源例句；覆盖质量依赖源词库，不保证每词有例句。不清空用户词库、旧数据库、自定义词典、收藏或已停用选择；已有词库可用就不需重新导入。失败的已识别 WTY 包仍经本人确认才修复。
- **缓存与收藏**：原句 100 条＋词典 100 批，各 30 天，按确切原文/语境/模型/推理区分。后台共享在途请求，明确取消才停止；清空不让在途结果回写。收藏最多 200 条，满后提示导出/清理，不淘汰旧收藏。旧的非个性化缓存仍可匹配；旧偏好对应的结果不再复用，但不批量清掉数据。旧详解快照仅兼容已有链接，不再新建入口。
- **AI 设置**：保留实际模型目录、受支持推理强度与缓存控制；默认 GPT-6.1 Sol / low，不自动换模型或失败重试。整块学习水平/目标/解释风格及记忆开关已删除，旧字段也不再传给模型。学习方向以后在实际学习和讨论中逐步确认，不新增自动画像或全文聊天抓取。
- **视频**：沿用 asbplayer 可检测字幕或手动 SRT/VTT；没有字幕不能自动取得台词，不把评论当对话。可取得时收藏带查词时播放位置，不能保证所有平台自动定位。播放器运行代码不变。
- **本机翻译**：macOS + Chrome，新电脑按统一包运行 `local-bridge/安装本机翻译桥.command`，需 Python、Codex CLI 0.162+ 和本机有效登录；这台 Mac 的自有桥随此次更新。首次点击授权既有 optional nativeMessaging，不扩大声明权限。使用账号额度，不声称免费或完全离线。
- **隐私与隔离**：只发送点选的有界句/词/补充语境，或当前词典批次与同句已有 AI 译文；URL、收藏全集、整页、聊天、Vault 和 Anki 数据不发给模型。Native Messaging 固定 Origin，无监听端口，独立受限 profile、空环境、关闭工具/MCP/插件/浏览器/子代理；认证及个人数据不打包。
- **边界**：当前「收藏语境」仍仅是扩展本地收藏；**Obsidian 生词主库→幂等 Anki 制卡→确认学习档案未实现**。原 Anki/音频按钮保留，不用离线 UI 或收藏冒充闭环。本版相关行为/隔离 fixture、类型/格式、真实源条目的明暗/窄屏离线预览和构建已核对，真实模型生成 0 次；用户 Chrome 重载后的交互、词典辅助中文质量、媒体与制卡另验。

## 更新与边界

独立公开扩展 key 固定本地版本 ID，与商店版分开；升级复用同一目录和同一 key，不再生成新 key。运行 `tools/check-upstream.sh` 只拉取并查看更新，不自动合并、推送或提交官方 PR。两个自有 fork 均只保留 `main`。后续官方更新适配到自己的 `main`，检查文案键、模板变量、权限与构建后再发布；不创建长期适配/备份分支。

验证记录与构建说明见 `docs/personal-build.md`。构建及静态检查不等于真实浏览器加载、词典首次导入或视频/制卡运行验收。
