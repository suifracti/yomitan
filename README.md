# yomitan 中文学习定制版

仅维护 [suifracti/yomitan](https://github.com/suifracti/yomitan)，不向官方仓库推送或提 PR。

## 下载与加载

请从本仓库 **[Releases](https://github.com/suifracti/yomitan/releases/tag/v2026.10.07-zh-study4)** 下载预构建安装包，不用 Code → Download ZIP（那是需构建的源码）。
两扩展统一包发布于 [asbplayer Releases](https://github.com/suifracti/asbplayer/releases/tag/v2026.10.07-zh-study4)。解压到固定目录，在 Chrome 扩展页启用开发者模式，分别“加载已解压的扩展”选择 `yomitan`、`asbplayer` 文件夹。不要同时启用商店原版，避免重复扫描或录音。

新安装已预设中文界面、AnkiConnect `127.0.0.1:8766`、牌组 `外语::英语语境`、笔记类型 `外语语境卡` 和七个字段；不会迁移或覆盖旧扩展数据。Yomitan 随包提供增强 ECDICT 英语学习词典，首次入门/设置页会自动导入，请等待提示就绪。Chrome 首次加载/授权须人工确认。Anki Desktop 必须运行且安装 AnkiConnect；此包不自动改任意机器的 Anki 数据库。

## 使用

- 文章/字幕：按住 **Shift** 悬停查词；中文释义由内置 ECDICT 提供。
- 视频：asbplayer 使用平台可检测字幕，或拖入自己的 SRT/VTT；不保证任意网站字幕自动可读。
- 视频语境制卡：使用 asbplayer 的制卡入口，或在 Yomitan 加词后用 asbplayer 更新上一张卡片补入音频/截图。普通查词制卡无需额外服务。
- **高级词汇状态标色依赖额外 yomitan-api 本机组件，当前包不启用。** 已预设 Word 字段和目标牌组，但不把配置称为已完成 Anki 复习回流。21 天等“成熟”阈值是软件规则，不是真实掌握。

## 当前版本：精简查词与点击式 AI 语境解释

`zh-study4` 默认展开主匹配，次要匹配为短行，点击或键盘选中再展开。原句只显示一次；词形/标签/词频收进一个资料栏，英文解释单独展开。保留原 Anki、音频及条目索引，不重建复习系统。

- ECDICT 770611 条保留真实源字段；仍不是完整例句词典，不保证覆盖所有义项。AI 语境解释明确独立标注，不冒充词典释义。
- **已有用户升级**：重新加载 Yomitan、刷新学习网页，打开设置查看“增强英语词典”状态。已改名/多配置、已删词典或已停用的用户不会被静默自动修改，可明确点击“升级／启用增强英语词典”。仅作用于开始操作时的当前配置，不删除旧 DB 或自定义词典。
- **本机翻译（macOS + Chrome）**：统一包解压后运行 `local-bridge/安装本机翻译桥.command` 一次；需要本机 Python 与 Codex CLI 0.162+，不把 CLI 装进浏览器。然后在查词卡点击“翻译原句”或“解释这里的用法”，首次按 Chrome 提示授权已有可选的本机通信权限。其他浏览器/系统未适配。
- 只发送当前原句（最多 2400 字）和查词内容（最多 128 字），不发送 URL、整页、笔记、词库或 Anki 数据；悬停不调用模型。网页提取可能不完整，可先“编辑原句”。支持取消，已产生的账号消耗不能撤销。
- 本机桥采用 Native Messaging，固定扩展 Origin、无网络监听端口；使用独立受限 CLI profile，模型环境访问为空、MCP/插件/命令/浏览器/子代理等关闭，遇到工具请求即停止。认证仅留在本机私有目录，通过已有本机文件认证链接复用；不打包凭据，不自动登录。
- 已授权的**一句真实测试**返回“我厌倦了每天做同样的事”，并解释 `tired of` 不是身体疲劳，耗时约 12 秒。隔离原型/配置/类型/离线布局检查通过，**Chrome 中实际点击与增强词库参与查词仍待本人确认**。不保证其他模型/网站、账号额度或长期速度。
- asbplayer 本轮运行代码不变，不用重载播放器；视频完整原句/音频、制卡和复习回流仍分别验收。

## 更新与边界

独立公开扩展 key 固定本地版本 ID，与商店版分开；升级复用同一目录和同一 key，不再生成新 key。运行 `tools/check-upstream.sh` 只拉取并查看更新，不自动合并、推送或提交官方 PR。两个自有 fork 均只保留 `main`。后续官方更新适配到自己的 `main`，检查文案键、模板变量、权限与构建后再发布；不创建长期适配/备份分支。

验证记录与构建说明见 `docs/personal-build.md`。构建及静态检查不等于真实浏览器加载、词典首次导入或视频/制卡运行验收。
