# yomitan 中文学习定制版

仅维护 [suifracti/yomitan](https://github.com/suifracti/yomitan)，不向官方仓库推送或提 PR。

## 下载与加载

请从本仓库 **[Releases](https://github.com/suifracti/yomitan/releases/tag/v2026.10.08-zh-study5)** 下载预构建安装包，不用 Code → Download ZIP（那是需构建的源码）。
两扩展统一包发布于 [asbplayer Releases](https://github.com/suifracti/asbplayer/releases/tag/v2026.10.08-zh-study5)。解压到固定目录，在 Chrome 扩展页启用开发者模式，分别“加载已解压的扩展”选择 `yomitan`、`asbplayer` 文件夹。不要同时启用商店原版，避免重复扫描或录音。

新安装已预设中文界面、AnkiConnect `127.0.0.1:8766`、牌组 `外语::英语语境`、笔记类型 `外语语境卡` 和七个字段；不会迁移或覆盖旧扩展数据。Yomitan 随包提供增强 ECDICT 英语学习词典，首次入门/设置页会自动导入，请等待提示就绪。Chrome 首次加载/授权须人工确认。Anki Desktop 必须运行且安装 AnkiConnect；此包不自动改任意机器的 Anki 数据库。

## 使用

- 文章/字幕：按住 **Shift** 悬停查词；中文释义由内置 ECDICT 提供。
- 视频：asbplayer 使用平台可检测字幕，或拖入自己的 SRT/VTT；不保证任意网站字幕自动可读。
- 视频语境制卡：使用 asbplayer 的制卡入口，或在 Yomitan 加词后用 asbplayer 更新上一张卡片补入音频/截图。普通查词制卡无需额外服务。
- **高级词汇状态标色依赖额外 yomitan-api 本机组件，当前包不启用。** 已预设 Word 字段和目标牌组，但不把配置称为已完成 Anki 复习回流。21 天等“成熟”阈值是软件规则，不是真实掌握。

## 当前版本：连续阅读卡片、缓存与 AI 设置

`zh-study5` 使用 **速览 / 词典 / 用法** 三个视图：速览显示主词、中文核心释义、原句和已生成的语境译文；完整释义、例句与长分析按需查看，不再把核心结果堆到底部。保留原 Anki/发音/键盘索引。

- **词典**：一份 ECDICT 770611 条作中文速览，补充 WTY/Wiktionary 英英详解与真实源例句。补充 ZIP 约 103 MiB，首次打开设置/入门页需保持页面打开等导入；已停用/删除的选择不反复覆盖，多配置/改名配置有手动入口。仅停用已识别的旧 ECDICT，不删数据库或自定义词典。词典页的两种来源是互补资料，不是两份 ECDICT。词条丰富度仍取决于源数据，不保证所有词有例句。
- **缓存**：点击才调用；同一句已生成译文可直接复用，同一词移开再回来恢复结果。后台持有在途请求，同一请求共享；移开只隐藏显示，明确“取消”才终止。持久缓存最多 100 条 / 30 天，模型、推理、语境与偏好区分；可关闭或清空，清空后在途结果不写回。已有 study4 结果没有缓存，首次仍需生成。
- **AI 设置**：卡片右上角直达独立设置页，选择本机目录返回的模型与受支持推理强度；不硬编码展示虚假的支持选项。默认仍为 GPT-6.1 Sol / low，不自动切换、不重试其他模型。读取模型目录不生成译文，实际账号访问与译文质量另行验收。
- **有限记忆**：显式学习水平、目标和中文解释偏好，可关闭/清空；不猜测掌握程度。主动点击“收藏语境”才存词、原句和可用来源，最多 200 条，满后提示导出/清理、不删除旧收藏。设置页可移除、清空或导出 JSON。不自动同步收藏到 Anki，也不建立第二套复习系统。
- **上下文**：文章本地扫描范围内的相邻句可点击带上；默认只发当前句。视频用可读字幕；不能从没有字幕的视频自动取得台词，也不把周围网页评论当对话。识别到字幕且只有一个可见视频时，主动收藏附查词时播放位置；YouTube 链接可带时间，其他站点保留位置文字，不保证任意平台一键跳转。可手动补充/修正原句和语境。
- **本机翻译（macOS + Chrome）**：统一包初次安装运行 `local-bridge/安装本机翻译桥.command`；本机需 Python 和 Codex CLI 0.162+，不会自动安装/登录。首次点击由 Chrome 授权已有 optional nativeMessaging，不扩大声明权限。使用账号额度，不声称免费或完全离线。
- **隐私与隔离**：只发送当前句、查词、所选补充语境、显式偏好和同句已有 AI 译文；URL、收藏全集、整页、Vault 与 Anki 数据不发给模型。Native Messaging 固定 Origin、无监听端口，独立受限 profile：空环境、关闭 MCP/插件/命令/浏览器/子代理，工具请求停止。认证和个人缓存/收藏只在本机，不进入源码或安装包。
- **验收**：旧版已由用户截图确认真实网页 AI 翻译可显示，也证实滚动和重复词典失败；本版通过相关行为、桥协议、实际词典样本导入、类型/格式与离线首屏布局。已读本机真实模型目录，**本轮真实生成调用为 0**；新 Chrome 运行与完整字幕/制卡/复习回流仍需重载后确认。asbplayer 运行代码不变。

## 更新与边界

独立公开扩展 key 固定本地版本 ID，与商店版分开；升级复用同一目录和同一 key，不再生成新 key。运行 `tools/check-upstream.sh` 只拉取并查看更新，不自动合并、推送或提交官方 PR。两个自有 fork 均只保留 `main`。后续官方更新适配到自己的 `main`，检查文案键、模板变量、权限与构建后再发布；不创建长期适配/备份分支。

验证记录与构建说明见 `docs/personal-build.md`。构建及静态检查不等于真实浏览器加载、词典首次导入或视频/制卡运行验收。
