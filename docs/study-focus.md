# 语境学习界面与双向读回

本页是已实现功能的说明，不是新的项目总规划。项目决定和协作边界仍在 Obsidian。基于 `61e45104029edbd9757210f9b68010552c3b3c5f`，保留此前词典取消、重试、单词聚合和保存规则。本次只接入 Yomitan；不宣称已同步改造 IINA 或 asbplayer 的宿主 UI。

## 从真实学习动作组织界面

第一页「词义与原句」只有一个主要内容滚动区：顶部固定词头、发音、简明中文及三个页面入口，中间依次显示完整原句、译文、邻句编辑和 AI 问答，底部固定原追问输入与「问 AI」「记住它」。输入默认一行，随文字最多扩到三行；极矮窗口会按可用高度进一步收紧输入，避免遮挡按钮。长内容只滚中间，不截断原句，也不再提供为内部限高而设的「展开原句」。没有真实原句时标记「暂无原句」，不补造语境。

第一页与「详细词典」共用一份当前词典的全部中文词性行，不再只取第一行。顶部最多显示两行，提供「全部词义 · 共 N 项」进入当前内容滚动区查看完整释义；两个页面切换保留展开状态，不产生新的小滚动框。这里是词典参考，不冒充按原句判断的 AI 解释。无中文时明确提示，不自动翻译。

「详细词典」直接显示完整英文释义与例句，不重复放中文简释和首义预览，也不再套两层折叠标题。翻译按钮位于英文区标题旁，原分组、计数与翻页位于本组内容下方；词形、考试标签、词频和快速词典卡放在默认收起的「词形与资料」中。取消、重试、缓存和义项译文仍由原词典控制器处理；范围提示收进按钮说明。没有删除不同词典的真实资料。

「我的记录」保持原有 Obsidian 理解与 Anki 卡片读回；缺权限或连接时明确说明，不显示伪造数量或掌握程度。

在 Yomitan 独立完整词卡的小搜索窗口中，已有查词结果默认收起旧搜索标题、选项和输入栏，优先展示中文第一义。页头「换词」可按需展开原输入栏及搜索选项；查询结果刷新时展开状态保留。没有词卡结果时原搜索窗口照常显示输入栏。针对约 400×250 的窗口去掉旧 290px 最小高度，保留复习与问答滚动。

“记住它”是主动作，默认沿用完整学习保存与 0/1 择卡；同一语境可以另加多张独立学习卡，不限制单词累计卡数。快速词典卡留在词典页，不与完整学习保存争夺主按钮。输入、取消、反馈、音频和保存按钮都是原控件/原处理函数，不创建平行的学习状态。

## 字段双向同步（2026-10-18）

「我的记录」仍读回当前词的笔记与卡片；完整「学习库」可按收藏、已保存、关联卡、待同步筛选并搜索已读取的记录。更多记录按页加载，未加载部分不冒充已经搜索。

显式保存后，后续译文和问答自动补充同一条记录，不再择卡。原句、译文、含义、来源与卡片问答按字段同步：单边修改写回另一端，两端同时改成不同内容时等待用户选择。只编辑笔记的「同步内容」区，或 Anki 卡面可见的对应内容；自由笔记、完整聊天和复习排程不互相覆盖。取消收藏只取消标记，不删除笔记或卡片。

关联已有卡片时保留两条语境各自的真实来源，只同步关联的复习问答；不为了共用一张卡把两个原句合成一个。缺失的笔记/卡片不会自动重建。Anki 关闭时只保存笔记、不择卡，旧卡同步暂停。断连保留待同步意图，恢复后重试，不重新调用学习模型。

## Obsidian：正文在前，机器资料在后

公共 `study_library.py` 继承 `study_library_core.py` 的受控读写并挂接 `study_note_view.py`；新增 `study_sync.py` 处理笔记内的字段基线、多卡和同步。没有第二数据库，没有新模型或排程服务。

新的英语按词聚合文档将完整 context 元数据放在各语境正文末尾；仍在同一 Markdown 中，仍保留所有 ID、版本和来源。旧 v1、混合 v1/v2 文档可读取；只有明确写入时才更新相应块。已确认的复习问答不再在“复习判断”中重复打印，判断理由折叠，等待/已同步/正常零卡分别显示。

HTML 注释不是加密，源码编辑模式仍能看到末尾元数据；阅读模式隐藏注释。不批量移动或改写旧笔记。

现有笔记需调整位置时，工具默认只读：

```sh
python3 tools/reformat-study-note.py --vault '/实际/Vault' --file '语境目录/记录/word--w原ID.md'
```

只有用户明确决定整理该篇，才加 `--apply --expected <上次显示的SHA256>`。工具只处理选中的单词文档，保留原正文与 ID，检查版本并备份，不发 Anki/模型请求。

## Anki：保留七字段与排程

`assets/study-review/` 沿用 `Word / Sentence / Definition / Source / URL / Audio / Image`。正面只放回忆提示和原句；答案、完整词典和媒体在背面分层。现有字段、卡片 ID、笔记类型、音频、图片与排程不删除、不重建。

已有模型不会因更新代码而静默改模板：

```sh
python3 tools/apply-study-card-view.py --model '外语语境卡'
```

默认仅检查。明确应用时加 `--apply --expected <检查所得fingerprint>`。工具先备份再改模板/CSS，并读回确认；拒绝字段不符、版本已变或包含多个模板的笔记类型，避免共享 CSS 影响其他卡型。它不调用添加卡片、修改字段、删除卡片或评分接口。

### 首页单滚动布局（2026-10-18 用户批准）

「带上邻句」保留在原句下方、编辑折叠区外；点击沿用原填入逻辑并展开编辑。编辑默认收起，展开后内容随中间区域滚动。中文词义和页签固定在顶部，输入与操作固定在底部。本轮取代此前原句／编辑区各自滚动的局部方案，不改变学习对象、模型、保存或制卡接口。

### 第二页与共同中文（2026-10-18 用户批准）

共同中文显示全部词性，不在第二页正文重复。英英默认直接显示、资料默认收起；仅展示层与原分组控件布局调整，不改模型、缓存、保存 API 或记录身份。

本轮还修复实际 WTY 页面中的空白分组：词典外层列表容器不再与其内部义项一起参与分页；嵌套子义项跟随父义项，避免隐藏父容器时把本组正文一并隐藏。没有删除原词典内容。

### 学习库、设置与灵活制卡（2026-10-18 用户批准）

- 正式设置入口为 `/settings.html#learning`，旧学习设置链接转向同一处；原 Anki 字段映射留作高级设置。全部新卡默认同一牌组，类型/来源/实际媒体用标签；按类型分组是可选配置，不自动创建牌组。
- 每张卡分别保存 ID、问答、类型、目标牌组和状态。「再加一张」支持独立编辑并多选提交，不会只换分类复制同一答案。默认目标变化不搬动已有卡，Anki 手动移动后的实际牌组会读回。
- 翻译只产生原句译文，追问保留解释；历史区区分两类。没有真实音频不生成听力材料，没有原句不编造例句。没有翻译/追问也能直接保存。
- 顶部「发音来源」与材料的「学习来源详情」分开；翻译/邻句共用紧凑工具行。手动卡编辑在中间同一个滚动区，不占固定提问/保存栏。
- 新 Native 动作：`libraryFavorite`、`libraryUpdate`、`libraryCardsAdd`、`libraryReconcile`。后者返回 `{...LibraryRecord, syncState, conflicts:[{key,local,remote}]}`；local 指 Obsidian，remote 指 Anki，选择用 `resolutions:{[key]:"local"|"remote"}`。新字段均兼容旧调用，旧记录不会批量迁移。
- 继续学习保留 recordId；编辑原句不重建记录。不同单词不沿用父对象记录 ID。浏览器现有存储只保留送达意图与关联，不另建学习数据库。

必要自检使用临时 Vault/Fake Anki、模拟学习模型和实际 Google Chrome 组件，不在正式记录上制造测试数据。真实使用需刷新原网页后重新打开词卡。
