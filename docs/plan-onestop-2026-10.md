# 一站式学习插件：下一轮方案（2026-10-21，GPT 实现，Claude 审查）

## Context

用户实际用下来，觉得"还差一些才能真实可用、方便用"。目标是做成**实用、可靠的一站式**工具：查词、标色、字幕、整页翻译、制卡都在一个插件里，体验不输沉浸式翻译 / 简约翻译。

截图暴露的问题：
1. 字幕栏选了「AI 模型」后，没地方选模型和推理强度。
2. 「暂停后自动继续」等下拉框是浏览器原生样式，很丑。
3. 视频内面板比简约翻译还难看。
4. 不能选字幕语言：只读播放器当前的轨道或默认轨道（`vendor/kiss/youtube-caption-source.js`），非学习语言的字幕选不了，也翻译不了。
5. 查词卡里「点『翻译本句』查看中文」这个提示多余。
6. 标色只针对存过的词，没存过的生词永远不提示。读完一篇文章，也没有办法批量标记。
7. 扩展图标弹窗里只有一个开关，标色、字幕、整页翻译的开关都不在那里。
8. 没有整页翻译，也就没有双语对照或只显示译文两种形式。

用户已确定：
- 标色：按水平自动标，加上「本页生词」一键批量标。
- 整页翻译：手动开启；可以记住网站；另有一个可选的"英文网页自动翻译"，默认关闭。

已有可复用：
- `tools/build_study_dictionary.py`：ECDICT（MIT 许可）转换脚本，里面已有考试标签 TAGS（中考 / 高考 / 四级 / 六级 / 考研 / TOEFL / IELTS / GRE）和 BNC / COCA 排名。
- `ext/js/study/free-translators.js`：googleTranslate、microsoftTranslate、chromeTranslate。
- `ext/js/study/subtitle-prefs.js`：全局翻译设置 `TRANSLATION_PREFS_KEY`。
- 设置页 `#model` / `#effort`（`ext/settings.html:591`，`data-translation-model`）。
- `ext/js/study/word-marks.js`：WordMarks、statusFor、hover tip。
- `libraryMarkKnown` / `manualKnown`。
- `open*` 消息走后台打开页面的做法（`study-service.js`，见 openStudySettings）。

## 分批（每批单独提交；遵守 roadmap「工作方式」：每项最多一个测试，不加多余配置和抽象）

### 批 1：统一的界面组件，修小问题
- **自绘控件 `study-ui.js`**（在 `ext/js/study/` 新建，只放下面这两种东西）：
  - `menuSelect`：点一下弹出选项列表，当前项打 ✓，样式和面板一致。所有页面内 UI（视频面板、字幕栏 ⋯、悬停提示）里的原生 `<select>` 都换成它。
  - `switchRow`：左边文字、右边开关的一行。替换页面内的勾选框。
- **视频内面板改成 YouTube 设置菜单的风格**：
  - 深色半透明背景、圆角 12px、每行 40px 高；
  - 每行左边是名称，右边是当前值加 ›，点开二级菜单。
  - 内容还是三行：字幕 / 跟读 / 字幕偏移。
- **字幕栏 ⋯ 菜单**：换成同样的行式风格（浅色主题）。
- **字幕栏选「AI 模型」时**：下面直接出现「模型」和「推理强度」两行，读写的是设置页同一份设置（`studySettingsV2` 的 model / effort），模型列表复用设置页的读取方式。选免费引擎、Apple 时这两行隐藏。
- **删除提示**：查词卡里的「点『翻译本句』查看中文」。

### 批 2：字幕语言可以选
- **字幕栏标题行加语言选择**：用 `menuSelect`，列出视频的全部字幕轨道。
  - 手动字幕排前，自动生成的标「自动」；
  - 默认选学习语言（en）的轨道。
- **不是学习语言的轨道**也能载入、显示，并翻译成中文。
  - 轨道本身就是中文时，不翻译。
  - 查词和标色只对英语生效；其他语言的字幕只读、只翻译。
- **改动位置**：`youtube-caption-source.js` 已经能拿到 `captionTracks`，补一个"按 languageCode/vssId 取指定轨道"的入口即可。其他网站继续沿用现在的读取方式。
- **记住选择**：同一个视频记住上次选的轨道，用现有的 `writeVideoState`。

### 批 3：按水平标色，加「本页生词」批量标记
- **词表数据**：
  - 在 `build_study_dictionary.py` 里顺带生成 `ext/data/study/word-levels.json`，内容是 `{word: [最低考试级别, COCA 排名]}`。
  - 只收有考试标签的词，加上 COCA 前 2 万的词，控制在约 1MB 以内。
- **设置**：「查词与词典 → 网页生词标色」里加一项「我的水平：高考 / 四级 / 六级 / 考研 / 雅思」。
- **新增一档「可能不认识」**：同时满足下面三条的词：
  - 级别高于"我的水平"（或者没有级别、COCA 排名 > 8000）；
  - 没存过；
  - 没标为认识。
  - 样式是最淡的虚线，可以在设置里单独关掉。功能词表（`caption-sidebar.js` 的 FUNCTION_WORDS）照旧排除。
- **新增「忽略」状态**（参考 Migaku 的 Ignored）：
  - 用于人名、品牌、缩写这类不需要学的词。
  - 被忽略的词永远不标色，不进「本页生词」和任何统计。
- **认识的词、忽略的词存在哪**：都存在桥目录的 `known-words.json`，格式为 `{known: [...], ignored: [...]}`，不放进 Vault。
  - 新增动作 `knownWords`，可以读取，也可以增删一批（分认识 / 忽略两种）。
  - `libraryMarkKnown` 对没存过的词，改为写入这里，不再报错。
  - 前端读取后与 `studyWordStatus` 合并使用。
  - 先改 roadmap 约定，再写代码。
- **本页生词**：
  - 扩展弹窗和悬停提示里都有入口：「本页生词（23）」。
  - 打开后是一个侧边浮层，列出本页所有「可能不认识」的词，每个带本页里的一句原句和中文简义（来自 ECDICT）。
  - 每个词默认是"认识"。用户只勾出**不认识**的，然后点一次「完成」：
    - 没勾的全部标为认识；
    - 勾了的进入"在学"，等同于对每个词点「记住它」，原句用本页那句。
  - 每个词旁边再放一个「忽略」小按钮。
  - 有撤销提示，持续 5 秒。
- **鼠标悬停快捷键**（参考 Migaku 的 K / I 键）：
  - 鼠标停在网页上的英文单词上时（不限于已标色的词）：
    - 按 K：标为认识；
    - 按 L：记住它，进入"在学"，原句用当前这句，等同点「记住它」；
    - 按 I：忽略。
  - 按完显示一条小提示「已标为认识 · 撤销」，持续 5 秒。
  - 光标在输入框、可编辑区域里时不生效；带 Ctrl / Alt / Cmd 时也不生效。
  - 悬停小释义的底部写一行键位提示：「K 认识 · L 记住 · I 忽略」。
  - 设置里有一个总开关，默认开。

### 批 4：整页翻译（基于简约翻译源码），加扩展弹窗的开关
- **为什么不自己从头写**：整页翻译要靠大量站点规则和细节才能做好，简约翻译（KISS Translator，GPL-3.0，和本项目许可兼容）已经做成熟了。仓库里已经有照搬它代码的先例：`ext/js/study/vendor/kiss/`，来源记录在 `SOURCE.md`。
- **第一步先调研，不写功能**：
  - 读 KISS 源码，找出整页翻译、悬停翻译、划词翻译这三块的核心模块：DOM 扫描和分段、站点规则、双语 / 替换渲染、还原。
  - 在 `vendor/kiss/SOURCE.md` 里写明打算引入哪些文件，包括行数和依赖。
  - **到这里就停，等 Claude 审查**：
    - 如果需要打包工具（React、npm 依赖），先停下来汇报；
    - 如果引入的代码超过约 1500 行，先停下来汇报。
- **引入方式**：
  - 能原样照搬的文件，照搬进 `vendor/kiss/`，不修改，并像现有做法一样记录 ref、路径和 SHA。
  - 必须改的，只做最小改动，并在 SOURCE.md 里写明改了什么。
  - 我们自己只写一个薄适配层 `ext/js/study/page-translate.js`，负责三件事：
    - 把翻译请求接到我们的全局翻译引擎（`free-translators.js` 或模型）；
    - 读写我们的开关和设置；
    - 用我们的样式。
  - 用 KISS 自带的全局规则，决定翻译哪些元素、跳过哪些。这一轮不做规则编辑界面、规则订阅和同步。
- **要求的行为**（KISS 已有的就直接用它的）：
  - 只翻译进入视口的段落，结果缓存。
  - 跳过代码、输入框、导航，以及已经是中文的段落。
  - **两种形式**：
    - 双语对照（默认）：译文插在原段落下面，灰色、字号略小；
    - 只显示译文：直接替换原文，鼠标悬停时显示原文。
  - 「显示原文」一键全部还原。
  - 用付费模型时，第一次先确认一次，和字幕栏的「翻译全文」一样。
- **快捷键**：Alt+A 切换翻译 / 原文。
- **扩展图标弹窗重排**，从上到下：
  1. 「英语学习」总开关（划词查询）；
  2. 一个大按钮「翻译本页」，下面一行是翻译形式「双语 / 只看译文」；
  3. 开关「总是翻译这个网站」，以及「英文网页自动翻译」（默认关）；
  4. 开关「网页生词标色」，旁边显示「本页生词 23 →」；
  5. 开关「视频字幕学习」；
  6. 「学习库（今天 23 张）」和「设置」。
- **设置页**：所有这些开关在设置页里各有一处对应设置，读写的是同一份数据，不是复制一份。

### 批 5：划词翻译、悬停段落翻译（同样基于简约翻译源码，走批 4 的适配层）
- **划词翻译**：
  - 在网页上选中 2 个词以上（短语或句子），选区旁边出现一个小「译」按钮，点击后弹出小卡片。
  - 卡片内容：
    - 译文（用全局翻译引擎）；
    - 按钮：「复制」「朗读」（复用查词卡现有的发音）「记住这句」（存成句子记录，复用句子英→中卡型）。
  - 只选中一个词时，仍走现有的 Yomitan 查词，不出现「译」按钮。
  - 设置项「划词翻译」三选一：「选中后显示小按钮」（默认）/「选中后直接翻译」/「关闭」。
  - 在输入框、可编辑区域里选中文字时，不出现「译」按钮。
- **悬停段落翻译**：
  - 鼠标停在一段文字上，按一下 Alt，就在这一段下面插入译文（双语对照）；再按一次，收起。
  - 用 KISS 的悬停翻译模块，经过批 4 的适配层，不要另写一套。
- **划词翻译的「译」按钮和卡片**：同样优先用 KISS 的划词模块。「记住这句」是我们自己加的按钮。
  - 快捷键在设置里可以改。
- **扩展图标弹窗**：在「翻译本页」下面加一行小字说明：「选中句子点『译』；鼠标停在段落上按 Alt 翻译这一段」。
- **这一轮不做**（以后再说）：输入框翻译、PDF / EPUB 翻译。

### 批 6：字幕快捷键（参考 Language Reactor）
- 在视频页、焦点不在输入框时生效：
  - A：上一句；
  - D：下一句；
  - S：重听本句；
  - Shift+S：用 0.75 倍速重听本句，播完恢复原来的速度。
- 这几个键 YouTube 自己没有占用。在其他网站上如果和网站自己的快捷键冲突，以我们的为准，但只在字幕已载入时生效。
- 跟读暂停时，原来的空格 / R 照旧可用。
- 字幕栏 ⋯ 菜单底部写一行键位提示；设置里有一个总开关，默认开。
