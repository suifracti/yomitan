## L-001 B站多P：有字幕不等于当前选集正确

触发：修改站点字幕发现、选集、URL 解析或来源缓存。

证据：[716e48a](https://github.com/suifracti/yomitan/commit/716e48aefb1e1546216c4f4c8d485ec3012b8df3) 的真实 diff。`bilibiliSources()` 先按 bvid 查询 pagelist；旧实现固定 `pages.data[0].cid`，所以第二 P 仍选第一 P。修复按 URL 的 p（默认1）选对应 cid，再查该 cid 的字幕列表。不是登录状态问题，也不需要重造字幕解析器。

## L-006 网页视频继续学习：读回轨道、恢复入口和状态合并必须一起接上

**下载 JSON 要能重新导入**：现有导出用 `startMs/endMs`，原通用 JSON 进口只认其他时间键。读自家导出时用 `rows` 的原文、译文与时间、明确语言及偏移；不替换文件中给其他工具使用的 `cues`，不让旧 `source.url` 取得任何权限。当前视频里同一导入文件后来手调的偏移优先，手调归零也是有效选择。一律作为当前页的手动文件，不开模型。见[实际下载再导入](youtube-study-wiring.md#2026-11-18-下载的字幕-json-可以读回来)。

**只翻几句的双语 VTT 也要能导回**：扩展生成的双语 VTT 在文件头用 `NOTE` 记录原轨语言，每条已有中文用 WebVTT 语言标签标记。读这种文件与自家 JSON 共用明确译文的恢复，不看中文比例，也不把译文变成可查原文；没有标记的旧字幕继续原识别。原文、译文里的尖括号按文字导出，VTT 仍用原始时间，保留偏移选 JSON。来源权限不变。[部分翻译往返](youtube-study-wiring.md#2026-11-19-只译了几句也能下载再导入双语-vtt)。

**跟读倒计时只属于当次暂停**：`shadowPausedId` 按播放器与实际暂停位置确认操作仍适用。跳转清掉旧提示和倒计时；换播放器或改偏移不沿用旧暂停，没有跳转时照常空格继续、按 R 重听或倒数继续。见[拖动进度的复现](youtube-study-wiring.md#2026-11-19-拖动视频进度不触发旧跟读倒计时)。

## L-007 视频已记词退回制卡：恢复原记录，而不是只带词和句子

**字幕栏的「先听，再看原句」**：用已保存的原句和秒数在当前英语轨唯一对回播放行；同一范围的多个义项只听一次，零个或多个匹配不选。按已匹配字幕的偏移后起止时间调 `YoutubeStudyContext.playRange`，无需渲染过那一行，保留搜索，不发查词或取声凭证；仍核播放器和来源，变动即停止。练习隐藏可控制的字幕层、暂停自动翻译和进度写入；只在点看原句时显示原文及已有译文。不建练习档案、不打分、不写排程。见[两次重复台词](youtube-study-wiring.md#2026-11-18-先听已记下的原声再揭晓原句)和[搜索时仍能回听](youtube-study-wiring.md#2026-11-19-字幕搜索不拦住已存原句的回听)。

**字幕合并开关不应让旧原句不能回听**：先查当前行；还没找到时，仅在同一英语轨对照原始行和既有规则合并句，采用原文和保存整秒唯一匹配的确切起止。换轨、来源或偏移仍结束旧一轮；同秒却不同文不猜。非当前行只能直接回听和打开原笔记，不借用当前行的译文或补存原声权限。见[合并和拆开各验证一次](youtube-study-wiring.md#2026-11-19-字幕合并或拆开后也能回听旧原句)。

**听完想回到当时记的意思**：`_beginListening` 按字幕行保留匹配的记录，去重的是待播行而非义项；揭晓后才显示各条笔记入口，换一句即清除。用 `openStudyRecord` 读原记录号并在搜索词卡里继续，传 `openPanel:false` 不自动显示制卡；没传这项的旧制卡入口照旧。搜索词卡不因此得到对原视频的取声权限。见[同一句不同义项的回听接续](youtube-study-wiring.md#2026-11-18-回听揭晓后接回原笔记)。

**回听揭晓优先看自己保存的中文**：以前只看当前字幕轨上已翻的内容。主动点「看原句」才用同来源的 `libraryVideoWords(cue)` 按原文和整秒读已匹配记录的译文，重复译文合并，并保留同一句不同的译法；换句等失效就丢旧回执。整份词表不带译文，老桥无返回仍用字幕轨已有译文。见[双语回听](youtube-study-wiring.md#2026-11-19-视频回听揭晓能看到已存译文)。

**只重练没听清的原句**：练习有明确末尾，不在最后一句之后悄悄循环。用现有字幕行 ID 暂记本人主动标出的句子，不拿英文文本或词义去重，也不从没播放、跳过或看答案推断掌握。下一轮仅重播这些行，并从空标记开始；换轨、退出、改偏移仍丢掉本轮状态，不写第二套学习记录。见[集中重听](youtube-study-wiring.md#2026-11-18-只重听自己标过没听清的句子)。

**学习库回视频听这一句**：`videoListenUrl` 只去掉已知站点的跳时参数，不动选集等来源标记。后端按原记录号读取，交接暂存扩展会话、绑定新标签及原视频的 media key；网址不带笔记资料。字幕偏移恢复后复用原句和保存秒数的唯一匹配，准备好不等于已经播放。没对上的读者可以先切轨或改偏移；受保护来源、已存记录号、制卡和排程不改。见[学习库到单句回听](youtube-study-wiring.md#2026-11-18-从学习库回原视频听这一句)。

**练习没录音时可回原视频听**：填空或最近卡点的答案揭晓后，复用列表的 `makeVideoListenButton`。只有没有可用录音、能从已存英语句子对回网页视频时才显示；点击才交接这条编号，失败留在本题，处理后可以再点。不是给听写题生成新录音，也不替本地文件打开浏览器。见[练习回视频](youtube-study-wiring.md#2026-11-18-原句复习揭晓后可回视频听)。

**给旧笔记补原声，不重新保存文字**：「回视频听／补原声」仍走原视频单句交接。揭晓后只从已对上的英语字幕按原词与原记录号打开原声面板；切到别的素材、失去来源、已有可用录音或属于受保护字幕时不能借用。点录音前读这条笔记的版本，之后只发原 `libraryMedia`，不经过 `rememberEntry`，也不用录完后才读的版本覆盖中途改动。默认不带视频或截图。见[回听及附件边界](youtube-study-wiring.md#2026-11-18-从学习库给旧笔记补原声)。

**原网页打不开，已存的本句音频仍可听**：学习库「详情 → 播放已存原声」只给确有本条音频附件的笔记。按照原记录号及历史目标找附件，复用已有附件名、路径、大小与内容校验；不从视频文件、相似句或 Anki 的其他卡借音。音频过大就复用本机分帧，完整收齐后只在学习库内存解码；不新增缓存、站点权限或附件写入。见[已有音频的独立播放](youtube-study-wiring.md#2026-11-18-原网页打不开也能播放已存原声)。

**打开的题目不能替换成后来重录的声音**：桥用原编号读当前附件并核内容；学习库再拿播放按钮所在的题面／详情已拿到的附件 SHA-256 比对，避免同一编号后来改句并重新采集时播错。对不上不解码，提示刷新；换题仍丢弃迟到结果。旧结果不带摘要时沿原桥校验，不请求额外正文。见[练习中的附件版本](youtube-study-wiring.md#2026-11-19-已打开的听写题不播放后来换过的原声)。

**录到了，不等于笔记已收到原声**：词卡在送出附件前可取消；一旦请求发出，显示正在保存，不承诺能撤销。仅接受对应记录、原句和采集范围的音频回执，才显示这次已存；失败前没有发送的新原声与送出后尚未确认分开说，既有文字与录音不自动重写。词卡和学习库用同一个已存附件引用；受保护的来源不因此解锁制卡。见[采集与保存的边界](youtube-study-wiring.md#2026-11-18-录到原声和保存原声分开确认)。

**保存原声不用打开 Anki**：旧 UI 把采集藏在制卡面板，关闭 Anki 连原声都录不了。现只在有可采集字幕的词卡上用「保存原声」替代禁用的「制卡」，只展开原有的音轨、可选截图或视频和保存回执，制卡控件隐藏且不能提交。Anki 开着时仍用原入口；无可采集来源不增按钮。保留原句身份、取消与待交卡保护。见[关闭 Anki 后实际录制和播放](youtube-study-wiring.md#2026-11-18-关闭-anki-也能保存原声)。

**原句改了，旧录音不是新句的原声**：新附件按保存时的原句、来源地址和整秒归属判断；旧附件没有这个字段时，只有仍能对回原记录身份才沿用。只改释义或译文不挡原声。学习库回听、词卡和桥上的新原声卡不借旧媒体，留着附件；重新采集音频后也不拿旧视频替代。已送达 Anki 的卡不在本步回写。见[改句后重新采集的验证](youtube-study-wiring.md#2026-11-18-原句改了不借旧录音)。

**整个视频回听不从学习库当前页拼**：`openVideoListening` 用记录确认来源，再由后台给 `libraryVideoWords` 提供 `sourceUrl`。桥把它与视频 key 核对后按同来源取笔记，保留既有上限；没时间的记录可列出但不进回听。队列按已确认字幕行的真实时间排序，重复台词也必须对回原来的时间。见[从同来源进入整轮回听](youtube-study-wiring.md#2026-11-18-从同来源原句回视频练一轮)。

**B 站同一选集的字幕栏、学习库和小结不要各算一份词数**：网页只能传自己的媒体 key，后台用当前顶层网址（iframe 则用自己的文档网址）校验并补来源；桥沿用同 BV／av、同 P 的规则。支持不了该字段的旧桥退回原 key；网页不能指定其他选集。小结选择内容也走同一组，原目标笔记、明确点击才写的规则、字幕轨和进度 key 不变。见[同 P 三处对照](youtube-study-wiring.md#2026-11-18-b-站同选集的已记词和小结对齐)。

**很多长原句让整份已记词读取失败**：原本一次返回 300 条可见原句和全部已制卡上下文，大于本机桥每帧 900,000 字节就整次失败，字符数不能代替 UTF-8 字节数。只在这项请求协商分帧，浏览器收齐后仍交付原样两份列表；不要把制卡上下文裁成前 300 条，否则会重复推荐早已制过的句子。小响应仍单帧、旧桥退回原请求；没有新索引、缓存或记录格式。见[长句回读反例](youtube-study-wiring.md#2026-11-18-视频记了很多长句也能读回)。

**已制卡不必等词状态变了才撤下推荐**：查词卡确认带视频时间的笔记已存时，后台给发起操作的标签页发无内容通知。开启的词表按当前来源重读，张数和排重均以原 `libraryVideoWords` 回执为准，不把笔记保存当成卡已送达。相同词状态不重写缓存；迟到的旧读回不改新结果，词表关着或正在回听不主动读。见[保存回执后的字幕词表](youtube-study-wiring.md#2026-11-19-视频词表在保存和制卡后刷新)。

**回听不该拖到下一句开头**：实际播放器的 `timeupdate` 不是句尾精确时钟。保留事件兜底，但按剩余媒体时间和倍速只安排一个句尾定时；播放、跳转完成、变速时重算，换媒体、退出或结束仍清除。独立 Chromium 同一音轨原先晚约 0.22–0.25 秒，改后本次晚不到 0.02 秒。没有增加持续轮询，也不追移用户的播放进度。见[实际整轮点播与读回](youtube-study-wiring.md#2026-11-18-独立浏览器串起整轮回听并缩短句尾延迟)。

字幕快捷键 S／Shift+S 也使用这个媒体时钟；读当前行的已校验时间，不另发词卡或原声令牌。Shift+S 以 0.75 倍重听，结束、手动离开这句或视频／字幕偏移变化时恢复原倍率，不把手动跳转暂停。偏移后的开头早于 0 时提示调整，不跳到别处。见[快捷键回听验证](youtube-study-wiring.md#2026-11-19-快捷键回听也停在准确的句尾)。

**循环本句也用同一个句尾时钟**：过去只跳到句首，播放器暂停时不会开始；播放后要等粗粒度的 `timeupdate`。现在用户点循环才开始播放，在此句结束时返回句首；手动拖到下一句、改偏移或换播放器等会清掉原循环，不拦新位置或抢着恢复播放。保留单次回听与跟读的原行为。[暂停点循环](youtube-study-wiring.md#2026-11-19-暂停时点循环也开始播放)

跨行短语「回听 N 行」与快捷键共用 `_playCaptionRange`：从命中首行到末行，按点击时的字幕偏移和原速播放，到末行停住。多个位置分别保留，筛选不变；不真的合并字幕，不取得词卡或原声权限。见[两处命中点播](youtube-study-wiring.md#2026-11-19-一键回听跨行字幕片段)。

**来源链接和记录编号不是同一回事。** 改视频分组键时看 `study_sources.py`（浏览器站点表由同一文件生成）；不能因此改 `entry_id` 或归档笔记的编号。没有实际播放时间就保留原链接：曾将分享地址的 83 秒写成 0 秒，也会把普通页面的章节锚点丢掉。只有确实知道时间，才为 YouTube/B站生成跳时链接；普通网页不加时间参数，本地文件在来源行只显示文件名。见[临时笔记复现](youtube-study-wiring.md#2026-11-18-来源链接不再从零秒开始)。

**本地文件地址不等于本地视频来源**：桥在 `source_url` 复用 `media_key_of`，要求本地文件名和现行时长标记；F5 放行普通 `file:` 导致的两组旧拒绝用例已恢复。格式不能代替播放器／字幕授权，不访问该文件。已有记录编号、正文、可读性与同名不同目录的隔离不变。见[拒绝与有效输入](youtube-study-wiring.md#2026-11-19-本地视频记笔记沿用同一份来源规则)。

**本地素材按完整来源集中复习**：学习库保留文件名纯文本，另给「同来源原句」内部入口。完整本地地址（含目录和已存时长标记）是索引范围，不是文件跳转目标；笔记、听写、播放器已记词、制卡排重与小结共用。播放器后台只从浏览器报告的本地文件地址加上时长标记，不接受另一个目录传入；旧桥不支持时提示更新，不用同名碰撞的短 key 猜。播放进度与原有小结文件位置未迁移，不读视频正文。见[学习库范围](youtube-study-wiring.md#2026-11-18-本地视频可以按原素材集中复习)与[侧栏和小结验证](youtube-study-wiring.md#2026-11-18-同名本地视频不再写进彼此的小结)。

**文章来源直达原句**：`study_sources.article_href` 用原句生成浏览器文本片段，合适的是不含已有锚点或视频时间的 HTTP(S) 页面（不含 YouTube/B 站，原文 3 词以上、最多 400 字符）。学习库、辨词义和新笔记共用派生链接，不用它替换保存的 URL 或编号。明确的章节锚点优先；浏览器找不到原句仍能打开页面，重复文本不能保证是哪一次。见[浏览器实际点击](youtube-study-wiring.md#2026-11-18-普通网页的出处也能回到原句)。

**找同一来源的已存原句**：「本页生词」从顶层消息来源打开学习库，不把笔记结果返回网页；学习库的来源行也能从这条记录打开「同来源原句」。两处共用 `source` 分类和分页只读索引。普通网页忽略章节／文本定位而保留查询和哈希路由；`page_source_key` 按 YouTube 视频 ID 或同一 B 站视频和选集归并不同跳时链接，未指定 B 站选集视为第 1 P。只改查询归组，不动原 URL、记录编号、字幕媒体 key 或制卡来源。见[12 条的浏览器往返](youtube-study-wiring.md#2026-11-18-从本页生词找回这篇文章的原句)、[同一选集的临时库对照](youtube-study-wiring.md#2026-11-18-从学习库找同来源的原句)。

**同一课程播放器壳可能有不同素材**：`mediaKeyOf` 是播放器的短键，不拿它替代笔记来源；进度身份见 L-006。`pageSourceKey` 对齐桥的 `page_source_key`，保留通用网页的查询和哈希路由、忽略普通锚点，YouTube 和 B 站仍按视频／选集归组。同页切到另一个来源，要停止旧会话和旧词卡的媒体权限；后台从浏览器当前 URL 补完整来源，词表、小结和同来源练习同组。旧桥辨不出普通网页的不退回短键。历史小结不迁移，新路由各有小结。见[同壳课程反例](youtube-study-wiring.md#2026-11-18-同播放器的不同课程不再混笔记)。

**不先找词，按素材集中回顾**：学习库「按素材」从已有记录索引聚合，命中一条也显示整份素材的数量，按最近保存排列。还与原句匹配的已存录音才计入「有原声」；这一数量是记录数，听写仍会去掉重复句。两种入口沿完整来源进入同一范围，不打开原视频、不自动播放或读出附件。旧桥不能列素材时，保留「全部」里的搜索；不另存素材表。见[素材入口与临时验证](youtube-study-wiring.md#2026-11-18-从素材直接回到原句和听写)。

**只复习一份素材的近期卡点**：素材卡的 `recall` 是原卡点资格在这份素材的记录数；源内练习用原 `scope: source` 首屏的 `recallRound`，先按当前搜索和完整来源筛选，再换不同义项。不凭标题、文件名或共用视频编号猜选集；普通原句仍按原顺序。旧桥没有源内题组时保留本素材原句，不用全库卡点顶替。见[来源范围验证](youtube-study-wiring.md#2026-11-18-按素材只复习本素材的卡点)。

## L-009 学习卡型只定义一次

## L-010 视频外观与翻译服务不能互相写回

翻译服务的名称、菜单文案、紧凑状态及有效键从 `translation-engines.js` 找；Microsoft 仅在原来已选时出现。两份已有配置的分工不变：`studySubtitlePrefs` 持有视频外观/跟读，`studyTranslationPrefs` 持有引擎和自动翻译。窗口只提交改动的字段，后台在现有写队列合并；字幕、查词、整页及权限判断按同一规则读取。仅旧配置实际带翻译选择时才迁移；迁移也从写入时的当前值开始，打开全新页面不为默认值写配置。

实际反例：同一时刻选择 Microsoft、关视频内字幕、开自动翻译，旧写法把前两项还原成 Google 和显示字幕。新写法三项都保留。不增加设置项、轮询或另一个存储，不因为换设置就调用所选服务。见[全局翻译选项验证](youtube-study-wiring.md#2026-11-18-翻译服务与字幕设置统一写入)。

**字幕偏好与已译原句分开**：在关闭自动翻译时手动翻长句，字幕外观通知会重绘段落，旧实现把成品清空。现在同一句已完成的译文保留；整张卡重绘时，只有现有按服务／语言／片段的内存缓存合起来等于已恢复译文，才恢复逐段排版，不再记一轮。重载丢失内存分段时仍显示已存整句译文。没开始翻不展示空框，换原句不继承旧译文；翻译服务、缓存和问答同步仍是原来源。见[逐段到重载的验证](youtube-study-wiring.md#2026-11-18-翻译完不因改字幕显示而丢译文)。

**原句旁显示什么，就保存什么**：同一句先用笔记读回或字幕带来的现成译文，再用实际已完成的分段／单句翻译，最后才用本句问答附带的译文。问答里可以有不同译法，但不会借「记住它」或制卡覆盖原句旁已有译文；仍可正常保存新解释，也不为已译原句重发请求。原有自动同步仍只补空字段。见[临时笔记读回验证](youtube-study-wiring.md#2026-11-18-保存原句旁显示的译文)。

**字幕翻译任务在换轨后失效**：旧流程取消队列，却让旧字幕会话负责解锁按钮；一换轨，它永远不再解锁。现在字幕读取器在换轨、重组字幕或明确取消时结束对应任务，晚到结果不改新轨；同行号也不能复用。未确认的费用提示一起收起；同页同时尝试整页和字幕翻译，一张确认条只同意自己的操作。已有同视频模型确认、已译进度和原服务缓存照旧。见[换轨验证](youtube-study-wiring.md#2026-11-18-字幕换轨不再锁住翻译)。

**同一轨切断句方式，已经翻完的精确原句可保留**：`_present` 在重组前留住已完成译文，只按原始行成员、时间和精确原文恢复；不能拿相同首行编号认作相同句子。切回逐条或合并可读回仍在本次会话的旧译文；新拆合不是旧译文的拼接，导入双语仍按文件原译显示。重新载入或换轨清空这份显示状态，服务缓存及晚到结果处理不变。见[同轨切换](youtube-study-wiring.md#2026-11-19-字幕重新断句时保留已完成的译文)。

**打开词卡不另翻正在翻译的字幕**：已经有译文时直接显示；正在请求时先打开词卡，借该行原有私有令牌和原句等同一批返回，不按英文串猜。取消、失败或等待超时则留「翻译本句」，不因设置通知自动补发；还没交给服务的字幕不挡住词卡翻译。复用的译文可随原句保存，不记作新的翻译轮次。见[浏览器双轨与请求数](youtube-study-wiring.md#2026-11-18-正在翻译的字幕与词卡共享结果)。

**免费请求不能因中途切设置变成付费**：整页翻译以同一个引擎快照做确认、缓存和发请求；后台以实际准备使用的全局引擎核 `expectedEngine`，改了就保留原文，提示重试，不自动改投。模型确认让当前页排队段落共用；本人点的单句仍不弹确认。见[切换竞态与替身验证](youtube-study-wiring.md#2026-11-19-整页翻译切服务不跳过费用确认)。

字幕批次同样带上整轮开始时的服务。字幕栏还没收到设置变化时，后台也不会把后续的免费批次发给模型。完成的字幕不重翻，失败的可以重试；原有切服务取消、全文费用确认以及 Chrome 本机翻译不另起一套。见[字幕批次的复现](youtube-study-wiring.md#2026-11-19-免费字幕翻译不转投模型)。

**网页翻译设置只交这次改动**：`page-prefs.js` 沿同一后台写队列合并，不用页面手头的整份设置重写。拖动、隐藏、恢复修改同站的独立字段；扩展菜单单站自动翻译只改这一站。旧设置不用迁移，翻译服务仍由原全局入口管理。见[跨标签交错写入](youtube-study-wiring.md#2026-11-19-三个入口不再互相盖掉网页翻译设置)。

**只看译文不等于不能用原网页的链接**：悬停的原文只是提示，不可点击。含链接或可用按钮的段落才给就地展开入口，靠原节点的隐藏类切换；不复制链接或改写地址和监听。键盘展开后把焦点送到原控件。纯文本、双语、单句和失败状态不多一个入口。见[原链接和键盘操作](youtube-study-wiring.md#2026-11-19-只看译文也能用原网页的链接)。

**翻译语言按原文位置，不只看网页外壳**：整页和悬停使用块上或祖先最近的 `lang`，划词使用选区元素；缓存把语言和服务一起作为键。同页英文与法文的 Pain 不共享，不把明确标注的非拉丁段落挡在排队之外。未标注用原网页／英语退路；英语记句入口不保存已标明的其他语言，朗读按原文语言选声音。不改翻译服务、网页自动开启规则或词卡。见[混合语言页面](youtube-study-wiring.md#2026-11-19-网页翻译按原文段落和选区的语言)。

**划词或悬停翻译可留在原处重试**：切服务只更新全局设置，明确点「重译」才启动本句，并等此次设置的回执。卡片送出前核选择与当前服务一致，不悄悄改投；保留固定状态与当时原句，过期页面/旧回执不盖新译文。行下模式失败才给「重试」。见[无语言包后的原卡重译](youtube-study-wiring.md#2026-11-19-划词翻译不用重新选中也能重试)。

**原文不变也可能要换译文**：网站只更改段落、祖先或页面的 `lang` 时，旧译文的文字快照仍一样。整页各段记住译文使用的来源语言；实际来源语言变了才撤旧译文、恢复原文，再排进现有视口队列。自带独立语言标注的段落若未受影响，不重翻；按同一语言和服务读回旧缓存；已主动翻译的单句不自动重建。见[动态语言验证](youtube-study-wiring.md#2026-11-19-网页换语言时撤掉旧译文)。

**整页没开时，行下译文也不能借给另一段原文**：已有的 `watchChanges` 随行下译文启用。选区失效、网页改写原文或把段落移走就拿掉对应译文，未变的段落保留，不自动翻译或修改网页原文；悬浮卡照旧。见[动态评论验证](youtube-study-wiring.md#2026-11-19-网页换掉评论时清掉旧的行下译文)。

**译文不在原段落后面时，原文不能继续藏起来**：网站移动原段落或只移除译文时，原段落仍然连接在页面，旧检查发现不了。现有 DOM 观察器核对译文是否仍紧跟原元素；失配就去掉旧译文、恢复原文，整页翻译的段落回到原视口队列。文本和服务未变时用同一缓存；不动网页内容和交互，不重建主动翻译的单句。见[动态段落验证](youtube-study-wiring.md#2026-11-19-网页挪段落后不会只剩空白)。

**显示原文后，长段落也要停止发送**：仅拦旧回执不够，原来已经开始的长文本还会继续发尾段。网页整页和单句的 `requestText` 按原先 2,200 字符分段，逐段发之前核原文与本次翻译。已经送出的片段仍由服务完成，保留按片段、语言和设置的缓存；旧回执不占用新一轮的等待状态。见[恢复原文时停止未发片段](youtube-study-wiring.md#2026-11-19-点显示原文后停止还没发送的翻译)。

## L-012 词形可以共用学习状态，同拼写不一定是同一个词

只在已保存记录明确给出词典原形时，共用该词的义项、网页标色和手动「认识了」；不从拼写猜。一条成熟的 charge「收费」和一条刚保存的 charges「指控」，两种词形都应看到两个意思，撤销后都回到部分掌握。认识 see 不等于认识名词 saw，认识 run 也不等于认识搭配 run into。搭配沿用自己的拼写和关联原词，整句不参与。

写入仍保留原来的记录 ID、原句、词形和卡片。词笔记可能把同拼写的不同原形放在同一文件，不能再拿整个文件的一个开关代替某个词的状态。旧标记照读不重写；显式点击后才记该原形、清掉同一原形旧的分散标记。不因撤销重算或改动 Anki。临时记录与浏览器按钮的验证见[交接](youtube-study-wiring.md#2026-11-18-从另一个词形找回两个义项)。

网页与字幕共用短义：40 字放不下时，部分掌握的词把还在学的义项排在前面。字幕挑句、计数、已制卡原句排重按 v2 里可选的 `lemma`；选中与回听仍用真实字幕的词形、原句和时间，不把原声中的 charges 换成 charge。旧桥没有此字段时沿用原来命中的词。见[字幕推荐案例](youtube-study-wiring.md#2026-11-18-字幕推荐给不同的词留位置)。

**用旧原句辨义或对照用法**：学习库首页搜索同一原形或已关联词形时，`study_senses.practice_material` 优先返回原来两种不同义项的 `practicePair`。如果不能出辨义题，却有两条明确归属同一义项的已存原句，另给 `practiceExamples`；旧版不会把它当辨义题。两种模式用同一入口，保留原词形、出处、记录号；同文重复不当两个例子，同一原句有不同读法时不拿来出题。不调用模型或评定掌握。见[两种 charge 的浏览器练习](youtube-study-wiring.md#2026-11-18-用自己的旧原句辨词义)、[同一个意思的实际用法](youtube-study-wiring.md#2026-11-18-对照同一义项的两条旧原句)。

**同义项先跨素材看用法**：有真正不同来源时，不取同一视频里的最新两句；复用同一素材分组，分享、跳时和播放地址不算不同素材。仍找不到两个不同来源就保留原来两句。已有译文跟随原笔记；辨义先选择再显示，用法对照直接显示，不为缺译文发请求。见[一个词从视频到文章](youtube-study-wiring.md#2026-11-18-同一个词去另一份素材看用法)。

**不制卡也可以用原句练填空**：「练原句填空」与辨词义共用现有练习区。能找题的桥先在同一筛选内用 `libraryList(practice: 'cloze')` 找可能的旧词句；`blankStudyWord` 仍与填空卡合用单词边界，只取有唯一空位的题，不从词形猜。同一句可有不同目标词，同一题面一轮练习只出现一次；已积累的候选留到下一组、不替普通列表翻页。旧桥用已读结果和原有源内分页。答案揭晓仍可打开原记录，不调模型或写复习结果。见[跨页填空](youtube-study-wiring.md#2026-11-19-练旧原句填空也不用先翻列表)。

**保存整句和记词是两种练习材料**：`kind:'sentence'` 是网页「记住这句」的既有记录，不用整句话作为一个词挖空。`libraryList(practice: 'translation')` 在当前分类内查有译文的英语整句，先去重再分页，不要求普通列表先读到。每组最多五句，先读再揭晓，保留来源和记录号；继续下一组才查后续。旧桥用已显示的候选，素材范围保留普通分页，不调用模型或保存自评。见[旧句跨页与旧桥](youtube-study-wiring.md#2026-11-19-旧整句不用先翻到那一页)。

**整句理解用自己的话练，不按措辞判对错**：写不写都能看旧译文；若已输入，则原句、自己的理解和保存的译文同时留在当前题。组末可用原练习队列重练手动标记的句子，重练从空白开始，不读取新题或提前翻页。作答、标记和这组进度均不写回，不评熟悉度。见[作答对照与重练](youtube-study-wiring.md#2026-11-19-拿自己的理解和旧译文对照)。

**同一句的已存译法是对照，不是额外题目**：从 `practice:'translation'` 已按来源和搜索筛好的同句记录找不同译法，只为最终本页题目附最多三条译文和标题。仍优先用独立整句笔记出题，一条英文只出一题，中译英先给原来的中文题面。揭晓后才显示其他译文；旧桥、无其他译文时原样，不为找替代译文读正文或调用服务。见[不同译法的题面与揭晓](youtube-study-wiring.md#2026-11-19-整句练习也能对照过去存下的其他译法)。

**看中文写英文仍用同一批双语句**：沿 `practice: 'translation'`、原分组和旧桥回退，不为反方向另筛或保存题。揭晓前只显示本人已存的中文，原声、英文与出处都在揭晓后才给；保留本人写法供对照，不当听写逐字判错。不发 AI 批改，不记作答或复习成绩。现在两种方向也能练「记住它」保存的词卡整句译文；只存词义不入题。索引里同一原句只取一次，独立整句笔记优先，保留所选笔记的原顺序与入口。见[反方向练习](youtube-study-wiring.md#2026-11-19-用保存的中文练英文表达)和[从查词笔记找题](youtube-study-wiring.md#2026-11-19-查词笔记也能练整句)。

**同一来源多页的练习不要停在列表第一页**：同来源不足五题时，只有点练习才继续读当前来源、搜索条件下的下一页；复用 `sentencePrompts` 去掉重复题，够五题或读完就停，不改可见列表的分页。取消、换分类或搜索后丢弃迟到页，不请求原声。见[跨页找题](youtube-study-wiring.md#2026-11-18-同来源原句能到下一页找题)。

**只拿确实卡住的旧原句复习**：旧 `contextMiss` 的记录号可能只是拿来归档该义项，不能据此认定原句；旧逻辑也没有比视频位置。现在按实际词与原句、来源和已存整秒位置找唯一记录，已打开的原笔记号可从义项列表确认意思。新事件的 `contextKey` 核对当时的词、句、来源、时间和义项，不复刻原文；旧事件不补造，改了原句就不冒充同一个卡点。学习库「最近没认出」只拿 30 天内的确切原句（已标认识的不进），不写练习或排程。见[同句两个时间点](youtube-study-wiring.md#2026-11-18-最近没认出回到真正卡过的原句)。

**词卡只在确切的已存原句可复习时直接开题**：不会因为一个词能记录卡点，就把任意旧句当作这次卡过的句子。桥确认入选后回 `recallRecordId`，词卡才给「从这句开始复习」；查到的最新列表还得以这个编号开头。旧桥、只记义项或原笔记不再符合条件时保留普通入口，不自动替选。完整词卡有 `.study-translation-actions` 时也要挂上原 `.study-stuck`；它属于原句滚动区，不放进底部固定的输入区。只测单独组件不会发现入口未挂上。见[词卡直达](youtube-study-wiring.md#2026-11-18-从词卡直达确切的原句复习)和[隔离浏览器完整链路](youtube-study-wiring.md#2026-11-18-完整词卡的卡点入口与回听联测)。

**复习最近卡点不用分开挑练法**：同一轮最多五条，优先用这条笔记仍有效的原声出听写；其他用唯一空位填空，无唯一空位就先看原句回想。揭晓才对照本人已存释义、译文和来源，可回原笔记。按编号区分同文本的不同卡点，点击才取原声，失效不借别句；借用原练习区，不加接口、模型或排程。见[混合练习回归](youtube-study-wiring.md#2026-11-18-一轮复习最近卡点)。

**最近卡点的一轮优先换不同义项**：桥从原索引筛选完整结果后，用已有 `sense_key` 挑题，不只看最近十条。同一词形的明确不同义项可各进一题，同义项的不同原句仍保留并可补题；没有明确义项的旧记录只按原形成组。列表分页、搜索和指定首句照旧，首屏可带最多五条 `recallRound`，旧桥无此字段仍能使用列表。见[临时库的一轮选句](youtube-study-wiring.md#2026-11-18-最近卡点一轮优先练不同义项)。

**最近卡点和同素材卡点可以接着练**：现有首屏选题外附同范围卡点数。只在点下一组时，把当次已出过的记录号传给同一 `libraryList`，桥排除后按原规则挑不同义项；同句不同义项或不同秒数仍按记录号区别。重练本组不重新读，离开不保存进度，旧桥无数量仍可练原来一组。见[下一组和原列表](youtube-study-wiring.md#2026-11-19-最近卡点可以接着练)。

**填空时可以先听自己的原句**：有附件才复用学习库原声按钮和 `libraryAudioRead`，只在点击后按同一笔记编号读取；题面留空不是自动读音。揭晓原句后也可听，换题或离开时停止并丢弃迟到的音频。没有附件或读失败仍可作答，不从其他记录借音。见[填空回听](youtube-study-wiring.md#2026-11-18-旧原句填空也可以先听原声)。

**先听原声再写下整句**：「练原声听写」使用相同练习区，但不先显示原句、词或译文；只挑仍对应本句的附件，不要求某个词只出现一次。核对时保留不一致的作答供自己对照；可跳过或直接看原文，离开或换题即停。点听写后，同一 `libraryList` 按当前范围和搜索词，从已有索引筛选有效附件、按原句去重再分页；旧桥拒绝可用已读的记录。不会为找题读取音频、合并收藏或逐页请求。见[原声听写流程](youtube-study-wiring.md#2026-11-18-学习库可以先听再写整句)与[跨页找录音](youtube-study-wiring.md#2026-11-18-旧录音不在第一页也能练听写)。

**五句是每组上限，不是一个素材只练五句**：组末「练下一组」先消耗已读听写页的剩余题目，不足再按原范围查下一页。不预读附件、不同步收藏，不把普通列表翻到别处。先重听本组未对上的句子不会前移听写页；主动进入下一组才结束本组，离开练习不保留进度。用 11 条录音元数据验证第 6 和第 11 句的去向，见[多组听写](youtube-study-wiring.md#2026-11-18-同一个素材可以连续练多组听写)。

**听写漏一个词不应标坏整句**：核对用保序的单词对齐，保留输入与原句的两行原样，只在未对齐的词下面划线；同一个词出现多次也按顺序比。忽略大小写、标点和重复空格，保留缩写里的撇号。只把明确提交却没对上的句子留到本轮重听，跳过和直接看不算错。跟原轮一样点击才播，进入重听时隐藏原句。见[漏写与重听验证](youtube-study-wiring.md#2026-11-18-听写核对标出漏词和错词)。

**在查词卡直接练这个词的旧原句**：用 v2 已明确保存的词形或原形打开同词练习；不要用标色的猜词规则替练习认词。不传眼前的句子、来源或记录号。已有可辨义／可对照材料优先，否则只从同原形的已存句做填空；没有可练的素材就保留同词列表，切分类或改词不再自动打开。见[早期查词到练习](youtube-study-wiring.md#2026-11-18-查词后直接练原来的句子)和下文当前范围。

**同词原句不是全文搜索**：旧查词练习只在首批搜索结果里筛词，列表和听写仍可能出现别的词。现在「我的记录」和「练旧原句」共用精确词范围，先由桥按已存原形筛选再分页；练习和原声查询沿用同一范围。不同来源及义项各保留原笔记号，列表直接看短义、原句和已有译文。同拼写的其他原形不混进来；旧桥提示去「全部」搜索，不把近似结果作精确匹配。见[两页的词形和义项对照](youtube-study-wiring.md#2026-11-18-按原形看跨来源的同词原句)。

如果「刚撤销，颜色又变回去」，先查后台发布顺序，不要改复习阈值。后台只发布最后一次 `refreshWordStatus`，网页、词卡和字幕共用桥已合并人工标记的 v2；旧的 `studyKnownWords` 只解释 v1 及更早的缓存。见[逆序返回案例](youtube-study-wiring.md#2026-11-18-刚撤销认识了旧刷新又把词标回去)。

**词积累多了，网页标色和字幕一起停在旧结果**：6,000 合成词头加真实形态的别名与短语，v2 约 1.34 MB，旧桥整次拒绝。与视频词表共用本机分帧，完整字典才写同一缓存；不裁词形、不改认识状态或原来的刷新周期。相同内容即使返回键顺序不同也不重写，否则每次刷新会让已打开的页重标并让字幕重算推荐。见[大词表验证](youtube-study-wiring.md#2026-11-18-词积累多了标色也能继续更新)。
