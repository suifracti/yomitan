## 工作方式（2026-11-10 与根入口对齐）

- 项目记忆的开工入口见 [AGENTS](../AGENTS.md)。遇错先查旧修复、当前版本与保留行为，重要取舍更新原记忆条目。
- 防御围绕真实外部输入、身份归属、持久化与同步冲突，不为不可能的状态堆分支，也不因“内部数据可信”移除已有真实风险防护。

## 统一开发：同一个事实只定义一次（2026-11-18）

目标不是把整个扩展改成同一个类，而是让开发者改一个事实不用猜还要改哪几份副本。每批接通实际调用方，再移除旧定义；既有笔记、卡片编号、人工牌组与排程不迁移。按以下顺序推进：

| 要改的事 | 统一到哪里；什么仍分开 |
|---|---|
| 卡型、阶段、需要的素材、默认子牌组 | 改 `local-bridge/study_cards.py`。词卡、学习库、类型和 Python 保存链读同源目录；题面模板仍在 `study-card-kinds.js`。保留手选语法卡、AI 原有选型范围和个人指定的牌组。 |
| 在 Anki 实际看到的题目 | 改 `assets/study-review/`，运行 `dev/sync-local.py --manifest-only` 打包到桥。新建英语模型、设置页只读检查和自愿更换外观的工具用同一份正面、背面和样式；字段相符不代表已采用学习版。检查只读模板，不读卡片；不借部署更换已有模板。对新听力题，正面手动回听，翻面再对照完整原句。 |
| 保存和制卡的结果 | `study_cards.card_progress` 从笔记里的回执算已确认、未确认和阶段；词卡/学习库由 `study-data.js:cardReceipt` 显示，视频栏和学习小结也用同一笔数。笔记已存不等于卡已送达，重试沿用原记录 ID。 |
| 消息、设置与界面 | 普通本机动作在 `local-bridge/study_protocol.py` 登记，`studyCall → StudyService → native` 转发。特权来源和参数仍在各自边界校验。翻译服务改 `translation-engines.js`，设置写入走 `writeSubtitlePrefs`；保留学习版控件和主题，不复制网页设置。 |
| 字幕与来源身份 | 视频分组参数/站点表改 `local-bridge/study_sources.py`（生成浏览器的 `media-rules.js`）；网页端用 `mediaKeyOf` 分组、`timedUrl` 打开出处。分组键、笔记 ID 与跳转链接不可互换。播放进度/字幕轨/偏移的小改动由 `writeVideoState` 交后台按视频写入，站点取轨和媒体授权仍分开。 |
| 测试、部署与交接 | 场景跟着实际入口验证。桥运行文件由 `bridge_files.py` 决定，安装、健康检查和 `dev/sync-local.py` 共用。同步只认 Git 版本，可重复执行。项目记忆找行为，当前交接找证据和下一步，不设第二套任务表。 |

普通网页的来源链接也尽量直达原句：没有已有锚点、不是视频，而且有合适的短原句时，`study_sources.article_href` 生成浏览器的 `#:~:text=` 链接。学习库、辨词义的出处、新笔记里的来源行共用它。记录的 URL、媒体分组和 ID 不改，旧笔记不重写。页面文字改变、不能准确定位或旧桥未返回链接时仍可打开网页。

「本页生词」可打开学习库的「同来源原句」。扩展从发出请求的顶层网页取网址，复用 `libraryList(scope=source)`：文章切换章节锚点也能找回，查询参数和哈希路由保留区别。进入此分类、搜索或翻页只读，不触发同步。原记录、来源链接和 ID 不变。

学习库来源行也可打开「同来源原句」，保留原有的网页、跳时或文本定位链接。YouTube 按视频 ID 合并分享、播放及跳时地址；B 站只在同 BV／av 和同一 P 内合并，省略选集相当于第 1 P。普通网页保持已有查询和哈希路由规则；不改原记录、播放进度的 key 或链接。

已保存的本地视频笔记也可以从来源行进「同来源原句」。文件名照旧为纯文本；链接只开学习库，使用保存时的完整本地来源（含路径及已有时长标记），不按文件名猜归属，不打开文件或跳回播放器。列表和听写使用同一范围，只读已保存记录和明确点播的原声附件。

本地视频的已记词、制卡推荐排重和学习小结也按这个完整来源选记录。后台用当前本地文件地址和读者已传的时长键拼回来源，不接受别的目录。短 key 继续用于观看进度，旧数据、小结的笔记路径和网页视频不迁移。旧桥读不到该范围时提示同步，不退回有同名冲突的短 key。

字幕栏「我在这个视频记的词」可直接「复习本视频」，沿用 `openPageLibrary` 和学习库的同来源筛选；来源由当前播放标签（或字幕所在 iframe）确认，本地只取当前直接打开文件的完整地址和时长标记。原句列表及听写无搜索词时按视频时间排列，时间未知的排在后面；搜索仍按原相关度，文章等无时间素材沿用既有顺序。本地文件显示时间但不可点开，不授予额外文件或播放器权限。IINA 不是本仓库当前运行入口，本次不接入。

英语字幕行的「笔记」点击后沿用 `libraryVideoWords`，只读同一来源、同一整秒且原文对应的已保存条目；后台必须核对并补全当前来源。界面只显示词和原有短义项（有才显示），保留同一句的多个义项，可各自打开原记录。不自动读笔记、播放、保存或制卡。若当前字幕同秒同文无法区分则不猜；旧桥不能查单句时仍可去「我在这个视频记的词」。

已读回明确笔记的词卡，在来源区可直接点「同来源原句」，使用这条笔记保存的完整来源进入原学习库筛选。普通查词不增入口，本地文件也只打开学习库；保留「学习库」首页及「打开来源」现有入口。

按原编号已读回的笔记，未启用词典或查不到词时仍使用原词卡展示原句、译文及「已保存的解释」，以笔记里的释义和说明为准；恢复的旧问答仍在历史，不盖过笔记。详细词典里说明查不到并给原设置入口。普通未保存查询照旧，不伪造词典条目或自动调用模型。

继续已读回的笔记时，词卡的翻译、追问、读记录及保存/制卡沿笔记原语言和编号；旧笔记没有语言仍按英语处理。当前词典配置属于另一语言时，不把它的词义套在旧笔记上，保留已存内容并从详细词典说明原因。不自动换配置，普通查词、字幕授权和复习排程不变。

学习库「按素材」用原 `libraryList(scope: 'sources')` 聚合已保存且有来源的记录，返回分页的 `sources`（原链接、标题、记录数和可用原声数）。同一素材沿现有 `page_source_key`，按最近保存排序；搜索命中任意关联记录即可找到素材，数量仍是整组的。可查看全部同来源原句，或直接进入原声听写，均不自动播放。只读同一索引，不另存素材表、不预读媒体；旧桥不支持时保留「全部」里的普通搜索。

切学习库分类时，只按最后选中的分类继续读取；已经过期、还没发出的列表请求不必再发。其他标签里的加星与取消仍就地更新本地收藏，不触发模型或列表全量刷新，晚到的旧读取不能把新取消的星标加回来。

学习库的「练原句填空」从当前筛选已读取的英语笔记里取最多五个不同题面，保留各自的原记录。只在保存的词或短语在原句中完整且唯一出现时出题，已有释义可当提示，但不露出答案。这条笔记有已存原声时可选听，不自动读或播、换题即停；原声不可用也不影响作答。可输入后核对原句用法，也可直接看答案；不评定掌握、不调用模型、不加卡或写练习记录。

「练原声听写」复用同一个练习区和五题上限，只使用仍对得上本句的已存录音。题面不显示单词、原句或译文；主动播放后可写下整句，核对或直接揭晓才显示原句、已有译文和继续学习入口。加载失败仍能跳过或看原文；不借其他记录的音频，不用合成语音补题。只读，不保存作答或改排程。点入口时用 `libraryList(practice: 'dictation')` 在现有分类和搜索范围内从索引筛选有对应录音、原句不重复的已存记录；不逐页扫描，也不预读附件或同步收藏。旧桥不支持时，只用当前已读列表，不改正常翻页。

每组听写最多五句。组末还有原声时可点「练下一组」，也可先重听本组没对上的句子。先用已返回而未练的句子，不够才按相同来源、分类、搜索词读取下一页；只在继续时读，不改变学习库列表的页码。返回列表、换分类或刷新后本次练习结束，不保存进度或作答。

学习库列表的「回视频听／补原声」沿用单句回听交接。没有可用录音的网页视频原句，在填空或最近卡点里揭晓答案后也能用同一个入口；主动点才按原记录号打开视频，不自动播放。视频里再揭晓，可从唯一匹配的英语字幕打开同一条笔记的原声面板，再点按钮录音；找不到原字幕时不借用别句。补录只附加到原记录，采集前记下笔记版本，不通过重新保存来改词义、译文、义项、来源或卡片。有有效原声、笔记在采集中改变或受保护字幕没有原来源权限时不覆盖。

听写核对按单词对齐两行，保留原拼写和标点以供对读；比较忽略大小写、标点和重复空格，但保留缩写里的撇号。本轮结束可只重听核对后没对上的句子，重新从隐藏原文开始；未提交、直接看原句和跳过不算错，不记录成绩、错题或排程。

「同来源原句」里主动点练习时，当前页不足五题可用原分页继续找同一来源（保留搜索词）；够五题或读完即停，可取消。不会展开正常列表，也不会为了找题读取音频；加载不全时仍可练已找到的题。

「最近没认出」只保留一个「复习最近卡点」入口，按已有卡点顺序取最多五条。原声仍对应当前原句时先听写；无可用录音时，能挖出唯一词就填空，否则读原句回想词义。揭晓后一起看原句、本人保存的释义、译文与出处，能回到确切的笔记。同一句在不同来源、秒数或义项里的卡点不合并。只在点播放时读该条录音，不借音、不调模型、不保存成绩，不改现有的 Anki 同步和排程；其余分类的专项练习不变。

词卡「一时没认出」区分这句确实进入最近卡点与只记到了已有词义：`libraryContextMiss` 在已有归属规则成立且当前记录可复习时返回 `recallRecordId`，否则返回空值；旧桥只确认记过，不保证原句可练。只有确定进入列表时才把原练习链接改成「从这句开始复习」。学习库用 `libraryList(scope: 'recent-recall', focus: {id})` 在原筛选范围内优先这条，仍需在最新结果里确认它才能自动开始；找不到或旧桥不能定位时不选别句冒充。没有额外记录、自动播放或模型调用。

学习库按词搜索时，原来的两种义项辨义优先。没有可区分的两种义项、但有同一已明确义项的两条不同原句时，同一入口改显示「用旧原句看用法」。并排看自己存的用法和出处，可各自回原笔记；不用同一句或不同义项硬凑，不调用模型、不记分。

英语词卡「我的记录」可打开「同词原句」直接看各个来源的已存词义、原句和译文；「练旧原句」也在同一列表里练，从练习返回仍看这个词。沿用 `libraryList(scope: 'word', word, query?, offset?)` 与原笔记分页，按已保存的词典原形关联词形，不把全文提到这个词的别的笔记或同形异根的词混入。范围内可用原搜索缩小结果；填空和听写也相同。旧链接保留；旧桥不支持时提示可以到「全部」搜索，不冒充同词结果。只读，不增加存储、配置或生成素材。

本页批量记词保留原有 5 秒撤销期。保存按顺序确认；`pageWordsSave` 回 `saved`（已确认笔记数）以及可选的 `error`、`colourIncomplete`。标色失败与笔记失败分开，不能把已经确认的笔记算成待重试。遇到中断，用户只补存有回执的未确认部分；整个回执收不到时先查本页原句，不盲重传。补存保持原页网址，后台校对消息来源；不再先清掉尚未确认的词的标记。

本机桥已经明确回 `vaultSaved: true` 后，扩展标记问答已送达或更新本地关联失败，不撤销该笔记的回执。浏览器回执可附带 `localSyncIncomplete: true`，批量只提示一次并保留已存数量；词卡及选句仍确认保存，不保证接下来的问答会自动补充。未获本机确认仍报原错误；本地问答没有被删，不另开队列、不自动重发已确认的笔记。

同词同句可以是不同义项。普通词卡从笔记打开、或在当前卡确认保存后，问答、反馈和自动补充同时按记录编号和原句来源区分。没有打开或确认具体笔记时，问答只留扩展，点「记住它」再送；不按最后读到的一条猜。只把本次送达的问答绑定到确认的编号；旧问答在桥提供对应轮次编号时仍能读回，未确认归属的保留在原会话。受校验的字幕仍按原字幕来源绑定，收藏、笔记 ID、卡片和排程不迁移。

从任一入口打开确切的已存笔记时，即使换了浏览器、没有本机问答缓存，词卡「学习历史」也可从原笔记只读恢复最近五轮。沿现有单条 `libraryRead` 明确请求，只取该记录中带合法轮次编号的已存正文；以编号合并本机问答，保留未送出的反馈。读回的问答只在历史，不盖过本人后改的含义，不因此写笔记、制卡或调用模型；缓存没有原轮次时只读。旧桥沿用本机历史，不重写旧笔记或增加存储。更早的完整历史仍留在原笔记。

`libraryRead` 默认返回指定编号的内容，笔记字段、版本、正文和所选问答用同一份内容生成；不另做相关正文检索或访问 Anki。确实需要相关学习历史的 AI 制卡草稿才显式传 `includeRelated: true`；旧桥不认此字段时按原请求读取。AI 解释原有的相关历史入口、逐条保存、关联和同步规则不变。

普通英语笔记的按编号读取复用学习库现有的增量索引定位。仅从配置内的原目标、原路径读取，并以实时读到的笔记为准，不拿缓存正文返回；同一请求只更新一次索引。找不到编号或索引有缺口时沿用原定位，任何一个编号有重复都不猜。旧文件名保留，字幕来源凭证和写入动作不改，索引不存入 Vault。

已保存笔记的自动追问只追加问答或反馈；通过 `libraryUpdate.fillMissing` 补齐当前还是空白的含义、译文、学习提示，不替换已有内容。补交时由桥核对当前值。升级前已在 `update:v2:` 队列的自动更新同样只补空白；选择「记住它」才按下述规则提交卡上的编辑。

刷新已存词卡时按原记录编号重读，不把浏览器历史里的快照当最新。保存已打开的笔记只提交此卡相对打开时改过的字段及新问答；别处改了其他字段，照常保留。提交前发现同一字段已改成不同值时，提示重新打开。已入队的手动更新携带这些字段的原值，本机桥在写入前核对；若另一端已改成不同值，原笔记不动，草稿留在学习库「待核对的改动」，不再自动补交。旧版已入队、没有原值的手动更新同样留待核对；旧桥不识别条件时不退回无条件写入。不改旧笔记格式、字幕权限或制卡规则。

词卡「我的记录」按笔记列简释、原句和来源，同句的两个义项分开，各自可以「继续学习」和打开原笔记，不复制完整问答。从笔记继续只带记录编号和语言，由搜索页读回；从这里打开不会重设当前词卡的问答对象。词卡使用与学习库相同的 `libraryList(scope: 'word')`，可传 `focus` 及当前来源，分页前优先已打开的编号和同原词形、原句、出处、视频时间的记录；多义或不能确认唯一时不自动关联。旧桥只退回不带 `focus` 的精确列表。Anki 先展示笔记里的关联回执，主动刷新才通过 `libraryMemory(ankiOnly: true)` 读 Anki，不做写入、补交或同步。AI 的相关正文搜索仍供问答，不能替词卡挑笔记。

弹窗里的已保存词卡标签也按明确记录号区分；同词同句不共用草稿。标签用短义区分不同义项。自动查到的候选笔记不是当前卡的身份，只有在当前卡确认保存、回执仍对应同一来源时才更新标签身份和恢复快照；保护字幕的原身份与权限不改变。

浏览器原待同步队列里，早期笔记更新没有保存足以核实的问答归属，且旧自动项可能已合并进手动项。保留原项不发、不和新更新合并；新更新用 `update:v2:` 键。学习库将这部分单列为「旧问答需核对」，可展开和复制原内容到正确的笔记，不提供盲目重试。已写入后等待核对的项目、收藏与正常的重新同步沿用原来行为。

**从 Anki 重建**：卡片的题目不是原词。新英语卡的 Source 在原笔记链接上记原词；视频秒数仍用同一字段原有的「视频位置」。旧卡只用能与原笔记或卡片编号对上的词，不从题干猜。学习库发现找不到原词时允许先填词：`libraryOrphan` 原有的 restore 可多传一个 `word`，ignore 不变。只关联已有 Anki 笔记，不因恢复重做卡或改排程。

恢复也使用原保存位置。新卡的来源链接保存既有 `targetId`；旧链接只能匹配设置里已有的 Vault 和记录目录，不能打开链接指定的路径。确实分不清时，学习库显示将写入的文件夹，用户点该按钮才随 restore 发送这个 `targetId`。同一 Anki 笔记已经关联就直接完成，不用卡片内容覆盖后来改好的词笔记。

选过具体意思的英语卡，恢复时沿用已经分配的义项、简释和词典原形，不重选或分配新编号。新卡的原记录编号只用于对照当前词句是否同一条，不拿它读取别处笔记或取得字幕权限。已有同词同句时，不能证明属于它的旧卡不自动合并。

卡型、本机动作或来源规则表修改后运行 `python3 -B dev/sync-local.py --manifest-only`，将生成的 ES 模块与桥哈希一起提交；平时不需要启动构建器。设置返回配置快照，普通学习接口返回记录/查询结果；后台私有的保存、目标解析、自动同步、词状态刷新不在通用转发表中。给新动作开放网页、设置页或特定字幕能力是单独的设计决定，不能从它“有一个名字”推导。

## 数据约定

### `libraryWordStatus` v2（B2 + B8 → F3 / F4 / F9）

后台读取包含手动认识/忽略的 `libraryWordStatus`，存到 `chrome.storage.local.studyWordStatus`，格式为 `{at, version, words, phrases}`。网页、词卡和字幕都用这一份结果；较早发起的刷新不能盖掉较晚的撤销，状态相同不重写也不触发重标。与视频词表共用本机分帧；这个动作通过 `wordStatusFrames: true` 协商，旧桥拒绝则沿用原请求。所有词和搭配收齐才发布，断连保留上次成功的结果。

```json
{
  "version": 2,
  "words": {
    "brick": {"s": "learning", "iv": 3, "lapses": 0, "senses": 1, "gloss": "砖"},
    "run":   {"s": "partial",  "iv": 40, "lapses": 1, "senses": 2, "gloss": "跑；经营"}
  },
  "phrases": {
    "run into": {"s": "learning", "gloss": "偶遇"}
  }
}
```

字段说明：
- `s` 的取值：
  - `new`：已保存，还没有卡；
  - `learning`：有卡，间隔 < 21 天；
  - `shaky`：近 30 天遗忘过，或用户点了「一时没认出」；
  - `familiar`：所有义项的卡间隔都 ≥ 21 天；
  - `known`：familiar，并且有第 3 阶段的卡；
  - `partial`：部分义项是 familiar 或 known，另一部分是 new、learning 或 shaky。
- `iv`、`lapses`：这个词所有卡里的最小间隔（天）和总遗忘次数；没有卡时省略。
- F4 另读可选 `newSense:true`：从已有 newSense 卡点事件得出，表示本人选过新意思；不改变原掌握度分档，不新增记录或配置。
- `gloss`：≤ 40 字的已存中文短义，给网页悬停和字幕推荐共用；部分掌握时优先展示还在学的意思，不能含句子、笔记或来源。完整义项仍从 `libraryWordSenses` 取。
- `lemma`（可选）：已存的不同拼写确实归属于同一原形时给出。字幕在学词计数、挑句和已制卡原句的排除都按这个词，不多占位置；点「制卡」仍查字幕里原本的词形和句子。旧桥没给时沿用命中的词。
- 复习数据仍在原自动同步的一轮内读取。首次按卡号分批；之后用 Anki 的修改时间对照，只为新增或有变化的卡取完整详情，缓存只留卡号、归属和复习数字，不留题面。旧缓存没有修改时间就重新读；旧 AnkiConnect 不提供修改时间时沿用原读法。最近遗忘用 `rated:30:1`（Again）判断，不从累计 lapses 猜发生日期。断连保留上次数据，没读到间隔不算已掌握。
- 「可以加会用卡」沿用十分钟一次的提醒：这条记录确实关联的认词或理解卡中，有一张间隔达到 21 天即可；已有或在等确认的会用卡不重复推荐。不从复制过的标签猜归属，不读笔记正文；没记卡型的老记录只按其已关联的笔记号查阶段标签。仍只返回记录编号和词，不自动制卡。
- 键名：小写的 word 和 lemma 都写入。已记录为同一原形的词形，查看义项、手动认识和撤销都作用于同一个词；复习间隔和每个义项的进度不改。旧的单独拼写标记也能读，撤销时不在另一词形留下覆盖。不靠截词尾推测笔记归属。
- 兼容：旧格式（`words` 的值是字符串 `"learning"`/`"known"`）前端照常处理。

- 声称卡在一条已存原句时，按实际词形、原句、来源和已存整秒位置唯一匹配；同一句有多个义项时按已确认义项核对。未找到原句但只有一个明确义项时，仍可记该义项的卡点；义项也分不清时不替用户归到第一条笔记。
- `recall`：把 `senseKey` 对应的义项计为 shaky，持续 30 天。
- 学习库「最近没认出」只显示 30 天内主动点「一时没认出」、且当时确切对应本条原句的记录，最新卡点优先，可用现有填空练一轮。不给旧的不确定卡点补归属，已标认识的词不进入此列表。只读，不添加复习记录、不改排程。
- 返回：`{"ok": true}`。

#### 保存新义项或搭配（沿用 `librarySave`，`entry` 新增可选字段）

- 新义项：`entry.sense = {"key": "new", "gloss": "经营"}`。由桥分配真正的键（`<lemma>#<n>`）；这个义项的掌握度从 `none` 开始。
- 搭配：`entry.kind = "expression"`、`entry.word = "run into"`、`entry.baseWord = "run"`。
- 不带这些字段时，行为和现在完全一样。
- 不改旧记录 ID，不批量迁移。旧语境在只读汇总中使用稳定的默认义项键；新带 `sense` 的记录 ID 纳入实际义项键，因此同句的新义项也不会继承旧卡掌握度。重复 `new` 保存按同语境和 gloss 复用已分配键，指定已有键则关联该义项。卡点事件附在已有的相关词记录上（优先当前语境/指定义项），不因点卡点而另建笔记或卡片；没有已保存词记录时提示先保存。
- 默认 `#1` 留给未细分的旧/普通语境，显式新义项从 `#2` 分配，避免以后一次普通保存误并入已经学会的新义项。最近 Again 的时间范围采用 [Anki 官方搜索语法](https://docs.ankiweb.net/manual/searching)。
