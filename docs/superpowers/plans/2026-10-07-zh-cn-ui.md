# yomitan 中文显示层实现计划

**Goal:** 完成用户已批准的界面汉化并保持可适配上游。
**Architecture:** 使用已有本地化资源（asbplayer）或独立可见文案映射（Yomitan），保留上游原功能。
**Execution:** 当前主代理独立执行，禁止子代理。

## Constraints
不改权限、网络、查词、制卡与调度；不上传用户数据；本地加载由用户进行；升级须重新验收。

- [x] 新增文案/占位符回归测试并观察失败。
- [x] 修改中文显示层资源，运行最小受影响测试。
- [x] 检查源代码 diff，确认权限/功能未改变。
- [ ] Chromium 构建，记录 SHA256 和未验证边界。
- [ ] 提交推送自己的 fork 分支；如需要仅在自己的 fork 创建 Draft PR；安装说明。
- [ ] 拉取上游到独立适配分支；重复文案与构建验证，不自动覆盖稳定包。

实际浏览器安装与运行验收待用户手动加载，未通过构建替代。上游未来适配为长期维护，不将本次未发生的更新写成已完成。
